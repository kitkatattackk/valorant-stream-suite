# Valorant Stream Suite

Build a polished Valorant Stream Bundle for my streamer-widget brand, OverlayNode. This is a coordinated set of three working widgets with a customization dashboard and transparent overlays for OBS.

The bundle includes:

Rank Tracker — player name, rank, RR out of 100, session wins/losses, and win streak.

Chat Box — readable chat bubbles with usernames, role badges, and distinct follow, subscription, and tip alerts.

Stream Goal — follower or subscriber goal with current count, target, progress bar, and a tasteful completion animation.

Visual direction

Make all three feel like one professionally designed collection:

Dark translucent panels, crisp typography, restrained borders, and a customizable accent color.

Default accent: warm coral red.

Compact layouts that keep gameplay visible.

Short, smooth animations with a reduced-motion option.

Excellent readability at actual stream size.

Avoid generic dashboard styling, excessive glow, and oversized cards.

Use original visual assets. Do not imply official Riot affiliation.

Include three coordinated presets: Competitive Dark, Clean Light, and Pastel. A shared theme updates every widget, with optional per-widget overrides.

Dashboard

Create a responsive dashboard with:

Navigation between Bundle Preview, Rank Tracker, Chat Box, and Stream Goal.

A large live preview showing all three widgets over a representative gameplay-style background.

Light, dark, and checkerboard preview backgrounds.

Shared controls for accent color, text color, panel opacity, font, corner radius, scale, and animation intensity
